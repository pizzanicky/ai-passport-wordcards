# FoloToy 发布准备

## 社区草稿

名称：随身词卡 / Pocket Wordcards。版本：0.1.4-dev。简介：面向 AI Passport 的高中英语词卡，支持离线英式发音、词性和中文释义，按学习轮次安排复习。三个实体键操作，无需联网。

兼容目标：FoloToy AI Passport，ESP32-C3 / 8 MB / 无 PSRAM / 240×320。应用二进制名称保留平台约定 `FoloToy-AI-Passport-full.bin`。发布包应包含完整镜像、SHA256、版本、兼容硬件、分区说明、安装/恢复说明、素材授权与更新说明；不得携带本机路径、密钥、缓存或私人原图。

## 发布前要求

1. 真机验收并填写实际硬件版本、启动日志、按键/音频/掉电/休眠结果。
2. 校订全部词条常用释义、词性、英式音标及高中范围；每条有审核记录。逐词或经明确审核规范听审音频，保留修改清单。
3. 审查 ECDICT 原始数据出处和分发许可，以及 Piper 模型、数据集、微调基模许可链；确认角色公开发行授权/署名。
4. 已核查官方 [英文开发指南](https://ai-passport.folotoy.cn/en/guides/create-your-own-play/)、[创作者中心](https://ai-passport.folotoy.cn/en/account/) 和 [当前分区表](https://github.com/FoloToy/ai-passport/blob/main/partitions.csv)（2026-10-04）。指南要求开发设备测试并交付 0x0 合并镜像；创作者中心登录后的字段尚不可见。当前独立音频分区需要三镜像安装，平台单文件兼容性待解决，不能用包含 cardid 间隙的合并镜像代替。发布前继续核查 FoloToy 当前应用提交入口、字段、封面尺寸、固件安装方式和审核规则；当前准备稿不宣称已经完成平台提交或审核。
5. 经授权创建独立公开 GitHub 仓库 `ai-passport-wordcards`，不 Fork、不添加原历史；仅提交本项目代码、允许分发的资产及必要 MIT/OFL 声明。提交前隐私/许可检查，记录首个提交和发布标签。
6. 对最终提交重跑完整验证，归档对应镜像/ELF/MAP/哈希；制作封面和原尺寸页面截图，清楚区分设备截图与主机预览。
7. 发布说明标明固件替换与数据影响，保留恢复原应用的公开说明链接。获得发布授权后提交平台，不把本地构建通过表述为上架成功。

当前阻止正式发布：词库审核、听审、许可链、角色发行授权、真机验收、平台安装兼容性及登录后提交字段核查。GitHub 尚未创建/推送，社区草稿尚未提交。
