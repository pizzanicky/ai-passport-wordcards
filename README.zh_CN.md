# 随身词卡

FoloToy AI Passport 完全离线背单词应用。当前为开发预览，尚未完成教学内容审核和真机验收。

已实现：首页、单词正面、释义、长释义阅读、完成页、进度、设置、音量、重置确认、版本与错误提示。使用获准的原创角色主题，配色为米白、酒红、雾青和深靛蓝。按 240×320、RGB565 和 30 px 圆角显示区域绘制。

首屏 OK 认识并进入下一词、↓ 再练并进入释义、↑ 发音。进入释义后播放再练音效并自动发音；该词保持再练，OK 随时进入下一词，短释义上键重听，长释义上下翻页。退出或重启后继续当前词的加强页。长按 OK 返回首页。60 秒不操作关闭背光，第一次按键只唤醒。

每轮最多 20 个不同词条，先排到期复习，再补最多 5 个新词。认识后的复习间隔依次为 1、2、4、8、16 轮；再练安排到下一轮。中断后继续当前词卡。

候选词库 3676 词，含音标、词性、中文释义和预生成的英式发音 MP3。播放无需联网；没有账户、在线模型、运行时语音合成、单词图片或例句。

激活 ESP-IDF 5.5.3 后，首次运行 `idf.py build` 获取锁定依赖，再执行 `./tools/validate.sh`。应用合并镜像位于 `build/FoloToy-AI-Passport-full.bin`，还需 `build/install/audioa.bin` 和 `build/install/wordaudio.bin` 两段音频镜像，按安装清单分开写入以保留 cardid 身份区；归档含 ELF、MAP、分区表和 SHA256。主机验证不能替代实际设备显示、按键、音频和掉电测试。

当前开发安装采用三个分开的镜像，尚未证明兼容平台单文件安装；不能把三个安装镜像填充合并后覆盖身份区。

默认声音音量 100%；升级旧进度时同步调整一次，后续手动设置继续保留。“认识”在评价保存成功后、“再练”在加强状态保存成功后分别播放原创上行/下行短音效，完全离线。
